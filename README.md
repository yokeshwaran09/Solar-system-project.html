# Solar System Project 🌍☀️

## 📌 About the Project
This project is a simple representation of the Solar System created using **HTML**. It displays information about the Sun and the planets in a structured format.

## 🎯 Project Objective
- Practice HTML fundamentals.
- Understand HTML page structure and elements.
- Learn how to organize and display content using HTML.

## 🛠️ Technologies Used
- HTML5

## 🌎 Features
- Displays the Solar System and its planets.
- Uses HTML elements to organize content.
- Beginner-friendly project demonstrating HTML skills.

## 📂 Project Structure
```text
Solar-System/
├── assets/
├── solarproject.html
└── README.md
```

## 🚀 How to Run
1. Clone or download this repository.
2. Open `solarproject.html` in your web browser.
3. Explore the Solar System project.
